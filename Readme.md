# 📦 Supply Chain Bottleneck Analysis

## 📌 Problem Statement
Identified delivery bottlenecks across shipping 
modes, regions and product categories using 
180,000+ real supply chain orders.

## 🛠️ Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook
- Dataset: DataCo Supply Chain (Kaggle)

## 📊 Key Findings
- Standard Class shipping had highest late rate
- Identified top 10 delayed product categories
- Late deliveries caused lower avg profit per order
